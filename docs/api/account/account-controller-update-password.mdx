**Tag:** `Account` &nbsp;·&nbsp; **Operation:** `AccountController_updatePassword`

## Purpose

Changes the password of the authenticated user. The body carries both the current and the new password; the backend rejects the call when the current one does not match. It is consumed by the change-password screen reachable from the profile area.

## Sequence

```mermaid
sequenceDiagram
  participant C as ChangePasswordScreen
  participant API as Backend
  participant DB as MongoDB
  C->>API: PUT /v1/account/password
  API->>DB: query
  DB-->>API: result
  API-->>C: 200
```

## Parameters

| Name | In | Required | Type | Description |
| ---- | -- | -------- | ---- | ----------- |
| `Authorization` | header | yes | `string` | Bearer accessToken |
| `Content-Type` | header | no | `string` | application/json |

## Request body

Schema: [`UpdatePasswordDto`](/data-model/update-password-dto)

| Property | Type | Required | Description |
| -------- | ---- | -------- | ----------- |
| `currentPassword` | `string` | yes |  |
| `newPassword` | `string` | yes |  |

## Responses

- **200** — User password succesfully updated — [`NewPairOfTokensDto`](/data-model/new-pair-of-tokens-dto)
- **400** — Some inputs are missed or wrong
- **401** — Invalid credentials
- **422** — Some inputs are invalid
- **429** — Too many requests, rate limit exceeded
- **500** — Error not handled
