**Tag:** `Account` &nbsp;·&nbsp; **Operation:** `AccountController_getProfile`

## Purpose

Returns a member's profile information — their name, last name, and email — for display in the app. It is the source of truth for any "signed in as" UI, but in normal operation the app reads this data from a local cache populated at sign-in, falling back to this call only when the cache is missing.
