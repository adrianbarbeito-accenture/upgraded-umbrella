**Tag:** `Poll` &nbsp;·&nbsp; **Operation:** `PollController_getPolls`

## Purpose

Returns the polls available to the signed-in member. The home tab uses this list alongside the event catalogue to render a single combined feed, so a member sees both "things to attend" and "things to weigh in on" in one place.
