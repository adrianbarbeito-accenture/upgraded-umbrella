**Tag:** `Poll` &nbsp;·&nbsp; **Operation:** `PollController_createPoll`

## Purpose

Creates a new poll attached to an event so an organizer can collect quick community feedback alongside the event itself. Polls are intentionally lightweight — one question, predefined options, one vote per member — so they can be created in seconds without slowing down the main event flow.
