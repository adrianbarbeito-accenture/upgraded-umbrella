**Tag:** `Event` &nbsp;·&nbsp; **Operation:** `EventController_getEvents`

## Purpose

Returns the catalogue of events available to the community. It is the public face of the product — the list that anyone, signed-in or not, can browse to see what's happening. Filtering and sorting happen on the client; the operation simply returns the catalogue and any joined-state flags relevant to the requesting member.
