**Tag:** `Event` &nbsp;·&nbsp; **Operation:** `EventController_deleteEvent`

## Purpose

Lets an organizer cancel an event they created. Deleting an event removes it from the catalogue and unsubscribes every member who had joined, so participants do not show up to a venue for an event that no longer exists. The action is final, so the mobile app guards it behind a confirmation step.
