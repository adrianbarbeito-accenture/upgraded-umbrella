**Tag:** `Event` &nbsp;·&nbsp; **Operation:** `EventController_createEvent`

## Purpose

Creates a new event from the payload supplied in `CreateEventDto`. The mobile create-event flow assembles the payload across several screens (type, date, location, image), but the actual call is issued at the end of the wizard rather than per step, which is why no individual screen is linked to this endpoint by the analyzer.

## Responses

- **201** — Event successfully created
- **400** — Some inputs are missed or wrong
- **401** — Invalid credentials
- **403** — Not enough privileges
- **429** — Too many requests, rate limit exceeded
- **500** — Error not handled
