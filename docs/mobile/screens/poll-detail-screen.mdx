## Purpose

Detail view for a single poll. It renders the poll's question, options, and any prior selection, and lets the user cast or change a vote. `PollDetailCubit` owns the selection state; the actual `POST /v1/polls/{pollId}/vote` call goes through the polls repository and is not picked up by the static analyzer.
