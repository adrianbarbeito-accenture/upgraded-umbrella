## Purpose

Bridge between registering and signing in for the first time. The member's email is already filled in from the previous step; they enter the one-time code that arrived in their inbox to confirm they own the address. If the code is missing or expired, the screen offers a one-tap way to send a fresh one. Only after this step is the member able to sign in.
