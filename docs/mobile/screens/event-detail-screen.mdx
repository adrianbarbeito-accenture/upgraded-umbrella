## Purpose

Where a member learns about a single event in detail. The screen presents the event's date and time, location, description, cover image, and the running list of attendees, and offers a single primary action — Join, or Leave if the member is already signed up. If the event is full, Join is disabled with a clear explanation rather than letting the member tap it and fail. The screen updates immediately when the action succeeds so the member's choice is reflected without a refresh.
