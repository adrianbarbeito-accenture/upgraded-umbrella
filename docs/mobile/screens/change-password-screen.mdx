## Purpose

Lets a signed-in user change their account password. The form collects the current password plus a new one, validates them through `ChangePasswordCubit`, and calls `PUT /v1/account/password` on submit. On success the user is returned to the profile area; on failure the cubit emits a state that the screen renders as an inline error.
