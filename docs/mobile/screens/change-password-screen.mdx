## Purpose

Where a signed-in member can rotate their password from inside the product. The member types their current password, picks a new one, and confirms it; on success the screen acknowledges the change and the member is returned to the profile area. If the current password is wrong, the screen shows the error inline and lets the member try again without losing the new password they had just typed.
