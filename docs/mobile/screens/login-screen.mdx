## Purpose

Email-and-password sign-in screen. `LoginCubit` validates the inputs locally and then issues `POST /v1/account/login`; on success it stores the token bundle and the screen navigates into the authenticated home graph. Server-side validation errors are surfaced through state changes that the screen renders as an inline message.
