## Purpose

First thing a signed-in member sees after launching the app. It combines the public event catalogue and the active polls into a single chronological feed, so the member can scan what's coming up in the community without choosing between two views. Pulling down refreshes the feed; the screen shows a friendly retry banner if the network is unreachable.
